Overview

I am developing an FPGA accelerator for the two-dimensional Poisson equation. A five-point finite-difference stencil produces a linear system solved with Conjugate Gradient. The planned hardware computes each matrix–vector product directly from neighboring grid values, avoiding storage of a sparse matrix. A fixed iteration count is intended to make execution time predictable.

So far, I have built a C++ floating-point reference solver, a software fixed-point model, and SystemVerilog modules for arithmetic, AXPY operations, dot products, packed memory, neighborhood fetching, and the Poisson stencil. RTL testbenches compare several blocks with generated reference vectors, including stencil configurations with different memory lane counts.

In a software study of four 16 × 16 cases over 20 Conjugate Gradient iterations, Q8.24 produced the lowest mean relative L2 error against the floating-point solution among Q16.16, Q12.20, and Q8.24: 3.55 × 10⁻⁵, with no detected arithmetic overflows. This is a software-model result, not an FPGA performance measurement. The complete hardware controller and end-to-end solver are planned; board-level accuracy, timing, cycle count, and resource use remain to be measured.
